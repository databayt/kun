## Canonical shape

```
src/components/atom/blur-image.tsx   # BlurImage: next/image + blur-xl scale-105 → blur-none scale-100 on load,
                                     #   placeholder="blur" + blurDataURL (static → stored → NEUTRAL_BLUR),
                                     #   `plain` for small logos/icons, motion-reduce safe
src/components/atom/<domain>-image.tsx  # optional domain primitive (mkan PropertyImage) — renders BlurImage,
                                     #   owns sizes/quality per variant, loader, fallback
src/lib/image-optimize.ts            # generateBlurDataURL(file, 16) — canvas, client-side, before the S3 PUT
src/lib/stock-blur-map.ts            # { [stockUrl]: dataURL } generated by a sharp script (fixed stock set)
prisma: blurDataURL String? | photoBlurs String[]   # stored next to the URL
```

### Rules

- Parent owns the box: `relative overflow-hidden bg-muted` + aspect ratio.
- No `opacity-0` in blur mode — next/image paints the LQIP as the `<img>`'s background.
- LCP hero gets a real LQIP (static import or stored), never the neutral one.
- LQIP made at upload or by a backfill script, never at request time.
- Exempt: SVG icons, `blob:`/`data:` previews, email/print/PDF, shadcn `AvatarImage`.

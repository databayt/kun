# Template Agent

Templates are the codebase equivalent of shadcn's **blocks**: complete page
layouts and major sections, previewed at `/templates`, documented per-template
at `/templates/<name>` (our enhancement — upstream /blocks has no MDX layer),
and installable via `npx codebase add <name>`.

## The 36 registered templates

`dashboard-01` · `sidebar-01..16` · `login-01`, `login-03`, `login-04` ·
`hero-01..03` · `signup-01..05` · `subscription-01..03` · `header-01`,
`header-02` · `footer-01`, `footer-02` · `leads-01`

⚠️ Registry `header-01`/`footer-01` are **not** the site chrome. The live
SiteHeader/SiteFooter live in `src/components/template/` and are protected —
see CLAUDE.md "Custom Parts — DO NOT DISTURB".

## Source of truth: new-york

```
src/registry/new-york/templates/<name>/   # SOURCE — edit here
src/registry/default/templates/<name>/    # GENERATED by pnpm build:registry
```

`syncStyles()` copies new-york → default and rewrites `@/registry/new-york/`
imports. Never edit `default/templates/` by hand.

## Registration flow (every new template)

1. Create `src/registry/new-york/templates/<name>/page.tsx`
   (+ `components/*`), naming `{type}-{number}` (e.g. `hero-04`).
2. Add the item to `src/registry/registry-templates.ts`: description,
   `registryDependencies`, `files` (page.tsx as `registry:page`, components
   as `registry:component`), `categories` (from `src/lib/categories.ts`),
   `meta.iframeHeight`.
3. `pnpm build:registry` — regenerates `default/`, the typed
   `src/__registry__/index.tsx`, `public/r/styles/*/<name>.json`, and
   `public/r/templates/*/<name>.json`.
4. Docs: `pnpm generate:template-docs` scaffolds
   `content/templates/(root)/<name>.mdx` (`<TemplatePreview name>` →
   Installation CodeTabs → Usage) and merges `meta.json`.
5. Verify `/templates` (featured), `/templates/<category>` (grid),
   `/templates/<name>` (docs), and `/view/templates/<name>` (full page) —
   in `/ar` too.

## Route anatomy

One hybrid route `src/app/[lang]/(root)/templates/[[...slug]]/page.tsx`:
no slug → featured grid · slug ∈ category slugs → deduped category grid ·
otherwise → MDX docs page (templatesSource + TemplatesSidebar + TOC).
The viewer (`src/components/root/template/template-viewer.tsx`) copy button
issues `npx codebase add <name>`.

## Design rules

- Compose from ui primitives and atoms; import via `@/registry/new-york/...`
  inside template sources so style sync can rewrite paths.
- RTL first: logical properties (`ms-/me-/ps-/pe-/start-/end-`); verify in
  the `/ar` viewer.
- Semantic tokens only; responsive from mobile up; `meta.iframeHeight`
  matched to real content height.
- Radix via the unified `radix-ui` package.

## Checklist

- [ ] Source under `new-york/templates/`, `{type}-{number}` name
- [ ] Registered in `registry-templates.ts` with files + categories + meta
- [ ] `pnpm build:registry` run (default/ regenerated, JSONs published)
- [ ] MDX docs page exists (`generate:template-docs`)
- [ ] Renders in featured/category/docs/full-page views, en + ar
- [ ] No physical direction classes; no `@radix-ui/react-*` imports

# Blender — the 3D lane

Blender 5.3 (GPL, free, verified original: `blender.sh install`) builds the scene; the agent writes it
as code, in stages, and **looks at a rendered frame after every stage**. Nothing is generated by a
paid service; assets are CC0 (Poly Haven) or built here. The finished frames go to /edit
(FilmCraft `assemble.mjs --deliver`, media.sh) like any other clip.

| Poly Haven assets in a script                                                                       | `scripts/kit/polyhaven.py` (public API, cache in `~/.local/share/databayt/polyhaven/`)                                                                                                                                                                  |
| Drive an **open** Blender, look at the viewport                                                     | `blender-lab` (screenshots, renders, port 9878) or `blender` MCP (ahujasid, :9876, safe mode on; its `search_assets`/`import_asset` for Poly Haven). `generate_3d`, `generate_gaussian_world`, Sketchfab = outside services: never without Abdout's yes |

Install / repair: `blender.sh install` (Blender), `blender.sh install-lab` (the official MCP:
sha256-pinned add-on + server). Both MCPs run model-written Python as the user: keep untrusted text
(asset descriptions, web pages) out of the code you send.

## Rules — the ones that keep scripts from failing

1. **5.x, not memory.** Training data is Blender 2.8–4.x. Look it up (blender-lab search) or
   introspect (`bl_rna.properties[...]`, `enum_items`, `hasattr`) before using anything uncertain.
   Known breaks in 5.x:
   - EEVEE's engine id is `BLENDER_EEVEE` again (not `_NEXT`): read the enum, assign in `try/except TypeError`.
   - `scene.node_tree` is gone; the compositor is `scene.compositing_node_group` (a NodeTree you
     create). Composite, Texture, Map Value, Sun Beams nodes were removed.
   - Actions are layered/slotted; Python is 3.13; enum values are UPPER_CASE.
   - **Sapling Tree Gen does not run on 5.x** — trees are Poly Haven models scattered with geometry nodes.
2. **Shader/compositor nodes by `.type`**, never by name (names are localised). Material colour goes
   on node inputs, not `material.diffuse_color`.
3. **`bpy.data` and `bmesh`, not `bpy.ops`**, in background mode (ops need a context and can "finish"
   having done nothing). No viewport exists headless: probe with a render, not a screenshot.
4. **Scene as code, in stages.** One idempotent module per stage (≤ ~150 lines, seeded, objects
   prefixed by the stage), run with `kit/stage.py` → a checkpoint `.blend` + a 480p probe PNG.
   **Look at every probe** before the next stage. Never one 1,000-line script.
5. **Print what was applied** (counts, bounding boxes, the settings actually set). A silent no-op
   is the commonest failure.
6. **Metres, Z up.** Size imported assets from their world bounding box; glTF comes in Y-up → Z-up.
7. Before any long render: check the frame range, the active camera, the output path, free disk
   (`render_chunks.sh` refuses below 8 GB) and **mains power** (`pmset -g batt`).

## Professional checklist (EEVEE, landscape / architecture)

- **Light:** Nishita sky + one Sun; low sun 10–25° for long shadows; match the reference photo's
  sun direction. World/reflection probe for sky and water reflections.
- **EEVEE:** ray tracing on (screen trace + probe fallback, low thickness), ray-traced shadows,
  64–128 samples, film filter 1.0–1.5 px, fast GI for bounce; volumetric haze only with a
  restricted depth; motion blur shutter 0.3–0.5. Benchmark one heavy frame before the full run.
- **Colour:** AgX view (a gentle look) for the film; `Standard` only where exact brand colours are
  the point (logos). Grade in the compositor (`kit/grade.py`): mild glare, vignette, grain.
- **Ground:** never one flat colour — macro variation, a murram/gravel road strip conformed to the
  terrain, shore gradient. **Vegetation:** hero trees near the camera, scattered instances (density
  masks, Poisson min distance, distance culling) further out; grass dense only near the path.
- **Water:** Principled, transmission 1, IOR 1.33, low roughness, bump ripples, depth colour ramp.
- **Camera:** a path through beats (`kit/camrig.py`), target Empty + Damped Track, 24–35 mm, eye
  height 1.5–1.7 m walking / 8–60 m drone, eased speed that never stops mid-move, a little Noise
  for a hand-held gimbal. Depth of field subtle. One continuous move reads as expensive; jerks and
  stops read as cheap.

## Recipes

- **glTF from three.js:** expose the page's scene (`window.SCENE`) and run `GLTFExporter`
  (`binary: true`) in headless Chrome; canvas textures must be drawn (`needsUpdate`) before export.
  In Blender: import, check scale against known dimensions, `kit/materials.remap_gltf_materials`,
  relink duplicate meshes as instances.
- **Chunked render:** `scripts/kit/render_chunks.sh <blend> <outdir> <start> <end> --chunk 240`
  renders, encodes each chunk to a CRF-12 mezzanine, deletes its PNGs, resumes after a kill, then
  concatenates to `full.mp4`. Hand that to `/edit` (`assemble.mjs --deliver`).
- **Stills camera** (zooms over still images, no 3D): `blender.sh stills` — see `/edit`.

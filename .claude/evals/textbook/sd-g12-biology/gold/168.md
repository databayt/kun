**استخدام فصائل الدم في قضايا الأطفال المشكوك في شرعيتهم**

أهمية علم الوراثة في نفي وإثبات البُنُوَّة في الأبناء المشكوك في شرعيتهم يتمثل في تحليل دم كل من الأم والطفل والأب المحتمل لتحديد فصيلة دم كل منهم ومن ثَمَّ تحديد فصائل الدم المحتملة للأبناء باستخدام التراكيب الوراثية المذكورة أعلاه، وكما هو موضح في الجدول التالي:

**الطُرُز المظهرية والجينية لفصائل دم الأبوين والفصائل الناتجة عنهما في الأبناء**

| فصائل دم الأبوين | الطُرُز الوراثية لفصائل دم الأبوين | فصائل دم الأبناء   |
| ---------------- | ---------------------------------- | ------------------ |
| O x O            | ii x ii                            | جميع الفصائل O     |
| A x O            | ii x $I^A I^A$                     | جميع الفصائل A     |
| A x O            | ii x $I^A i$                       | 1A : 1O            |
| B x O            | $I^B I^B$ x ii                     | جميع الفصائل B     |
| B x O            | $I^B i$ x ii                       | 1B : 1O            |
| AB x O           | $I^A I^B$ x ii                     | 1A : 1B            |
| A x A            | $I^A I^A$ x $I^A I^A$ or $I^A i$   | جميع الفصائل A     |
| A x A            | $I^A i$ x $I^A i$                  | 1O : 3A            |
| B x A            | $I^A I^A$ x $I^B I^B$              | جميع الفصائل AB    |
| B x A            | $I^A i$ x $I^B I^B$                | 1B : 1AB           |
| B x A            | $I^A I^A$ x $I^B i$                | 1A : 1AB           |
| B x A            | $I^A i$ x $I^B i$                  | 1O : 1AB : 1B : 1A |
| AB x A           | $I^A I^A$ x $I^A I^B$              | 1AB : 1A           |

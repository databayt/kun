Say a name and the work lands in the right place. Nothing here is typed as a command: the router reads each prompt, finds the repository and block names in it, and hands Claude a one-line pointer to the folder (and, where a block keeps records, to the records to read first).

## How to say it

| You are in | You say | What happens |
| --- | --- | --- |
| the block's own repo | the block's name — `admission` | hogwarts: the full block protocol. Other repos: one line pointing at the block's records, if it has any |
| any other repo | the repo and the block — `mkan booking`, `food kitchen`, `in kun, the seek console` | a pointer to that repo and to the block's folder |
| any other repo | a **unique** block's name alone — `timetable`, `parent portal` | a hint that the word may mean that block |

## Classes

Every block key gets one class when the index is built. Nobody keeps this list by hand.

- **unique** — one repo owns the word and nothing else in the engine uses it. It works alone from any session.
- **shared** — several repos have a block of that name, or the word is already a repo, a skill, an agent or a spell. It works alone inside its own repo; anywhere else, say the repo with it.
- **common** — a plain single word (`form`, `file`, `settings`). Same rule as shared.

To make a plain word work alone from anywhere, add it to `resolver.always_bare` in `.claude/engine.json` and rebuild the index (`node .claude/scripts/resolve.mjs --build`). To give a repo its block list, run `node .claude/scripts/generate-blocks.mjs <repo>`.

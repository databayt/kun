**Kun (كن) is a code machine that collapses time between idea and product.**

Traditional development and business automation make you stitch together disconnected tools, operate custom server infrastructure, and juggle separate platforms for coding, planning, marketing, and sales — burning tokens and attention on the seams between them.

**Kun** dispatches the work instead. Every task is routed token-efficiently across a fleet of models and effort levels — a cheap lane for a rename, the deepest reasoning for an architecture migration — and it runs around the clock under one controllable configuration. The right model, at the right effort, on the right task: orchestrated and delegated automatically from a single keyword. It transforms Anthropic's product suite alongside Antigravity, OpenCode, and Hermes into a single, unified company OS.

## 4 Operating Lanes

Universal capability: every machine receives the full fleet, routed by task weight:

| Lane | Command | Agent / Engine | Workload |
|:-----|:-------:|:---------------|:---------|
| **Primary** | `c` | [**Claude Code**](/docs/claude-code) | Full build, schema migrations, deep QA, architecture, releases |
| **Secondary** | `a` | [**Antigravity**](/docs/antigravity) | Cheap off-pool lane (Gemini Flash) — quick edits, renames, lookups |
| **Tertiary** | `o` | **OpenCode** | Fallback CLI runner |
| **Gateway** | `h` | [**Hermes**](/docs/hermes) | Asynchronous messaging bus & Slack/WhatsApp relay |

## Core Principles

1. **Configure over build** — Don't rebuild what Anthropic ships.
2. **Architecture over vibe coding** — Humans design, AI generates within strict rules.
3. **Guardrails as training data** — Every clean component enforces the next.
4. **Full spectrum** — The engine runs the business, not just the code.
5. **Open source, shared economy** — SSPL public repos, sustain through real-world value.

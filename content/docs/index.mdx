# Kun (كن)

> **Configure over build.** The markdown & JSON configuration layer that transforms Claude Code, Antigravity, OpenCode, Hermes, and Cowork into a single unified company OS — running engineering, business operations, and multi-brand social distribution for **Databayt**.

Say the word. The engine coordinates **14 repositories, 8 people, 5 products**, and every tool in the stack.

> 🚀 **Quickstart**: [`bash <(curl -sL https://kun.databayt.org/install)`](/docs/onboarding) sets up any fresh Mac, Linux, or Windows machine into a fully provisioned node in one command.

## 4 Operating Lanes

Universal capability: every machine receives the full fleet, routed by task weight:

| Lane | Command | Agent / Engine | Workload |
|:-----|:-------:|:---------------|:---------|

| **Gateway** | `h` | [**Hermes**](/docs/hermes) | Asynchronous messaging bus & Slack/WhatsApp relay |

## Dual Execution Pipelines

### 1. Feature Pipeline · *Code to Production*

```
IDEA ──► SPEC ──► [PLAN ──► TASKS] ──► SCHEMA ──► CODE ──► WIRE ──► CHECK ──► SHIP ──► WATCH
                  └── human gate ──┘
```
*Trigger: `feature <name>` chains all 9 stages; each stage is also an independent skill with its own exit gate.*

### 2. Social & Media Pipeline · *Product to Audience*

```
CALENDAR ──► DRAFT (AR-first) ──► ASSETS (Media/Record/Higgs) ──► APPROVE (/social/publish) ──► PUBLISH ──► MEASURE
```

- **[Social Automation](/docs/social)**: Multi-channel broadcasting across 5 brands & 8 platforms.
- **[Product Videography (`record`)](/docs/record)**: Autonomous OTP handling, ad-grade video cuts, and screenshot archives in `~/media/` synced to Google Drive.
- **[Media Studio (`higgs` · `carousel`)](/docs/media)**: Generative image/video marketing & bilingual slide decks.

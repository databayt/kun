# سيك (Seek)

> **ابحث عن الفرصة، وقدّم، وتابع — تلقائيًا، باسمك أنت، ومن حقائقك أنت.**

**سيك** حلقة مفتوحة تعمل داخل Claude Code لديك. كل يوم تنجز ما يحتاجه البحث عن وظيفة أو منحة أو
تمويل، وما لا يجد أحد وقتًا له:

1. **اكتشاف** — تمسح لوحات الوظائف وبوابات التقديم ونتائج البحث، وتحذف المكرر والمنتهي.
2. **تفصيل** — تكتب سيرة ذاتية وخطاب تغطية أو عرضًا أو مقترحًا لهذه الفرصة بالذات، من الحقائق
   الموجودة في ملفك وسيرك الذاتية فقط.
3. **تقديم** — بالبريد أو البوابة أو النموذج، بحدود يومية ومهلة مراجعة قبل الإرسال.
4. **متابعة** — رسالة في اليوم السابع والرابع عشر، ثم أرشفة هادئة.
5. **إخطار** — تقرأ الردود وتصنّفها، وتنبهك فقط لما يهم: رد، مقابلة، عرض.

تعمل على جهازك وباشتراك Claude الخاص بك. لا حساب تنشئه، ولا تصل إلينا أي من بياناتك. الصفحة
العامة: [/seek](/ar/seek).

## المسارات

الحلقة واحدة لكل أنواع الفرص. ما يتغير في كل **مسار** هو مصدر الفرص، والمستندات التي تحتاجها،
والردود التي تستحق إخطارًا.

| المسار | الحالة | ما يكتبه |
|---|---|---|
| **وظائف وأعمال حرة** | يعمل | سيرة ذاتية، خطاب تغطية، إجابات النماذج، مقترح |
| **منح دراسية وزمالات** | قريبًا | سيرة ذاتية، خطاب الغرض، قائمة المستندات |
| **القبول الجامعي** | قريبًا | سيرة ذاتية، خطاب الغرض، قائمة المستندات |
| **التأشيرة والإقامة** | قريبًا | خطاب تغطية، قائمة المستندات، إجابات النماذج |
| **التمويل والمنح** | قريبًا | عرض تقديمي، مقترح، إجابات النماذج |

## الإعداد

```bash
git clone https://github.com/databayt/kun && cd kun && pnpm install
mkdir -p seek && cp scripts/seek/profile.example.json seek/profile.json
```

ثم املأ `seek/profile.json`: هويتك (`identity`)، وما تسأل عنه نماذج التقديم، وموجز البحث اليومي
(`seek.sweep`)، وأولوياتك (`seek.strategy`)، وقواعد عرض سيرتك (`seek.tailorRules`). اترك الحقل
فارغًا بدل التخمين — الحلقة توقف الطلب وتسألك بدل أن تخترع إجابة.

ضع سيرك الذاتية في `seek/cv/` وشغّل `pnpm seek:facts`؛ ملف `facts.json` الناتج هو المصدر الوحيد
للأرقام والشهادات التي يُسمح للخطاب بذكرها.

## التشغيل

افتح Claude Code في المجلد وقل **«seek»**، أو شغّل الخطوات بنفسك: `pnpm seek:google` ثم
`pnpm seek:wave` ثم `pnpm seek:send --apply`، أو الحلقة كاملة كل ٣٠ دقيقة عبر
`pnpm seek:loop --install`.

## الضوابط

- **الصدق:** كل رقم وتاريخ وشهادة في الخطاب يجب أن يكون في حقائقك أو في الإعلان.
- **باسمك فقط:** الملف لصاحبه، ولا تُشغَّل الحلقة لشخص لم يُعدّها بنفسه.
- **حدود ومهلة:** حد يومي، وطلب واحد لكل جهة، ومهلة يمكنك فيها إلغاء أي طلب.
- **مفتاح الإيقاف:** `pnpm seek:loop --pause` يوقف كل الإرسال فورًا.

# Shoot

`shoot` takes stills of real product pages and scripted flows, framed like Abdout's
14" MacBook at Chrome 125%, and its sim films the same flow into a branded tutorial.
Say it in prose: _"shoot add-student in both languages"_, _"publish the bulk flows"_.
Raw screen takes are [record](/docs/record); cuts and reels are [edit](/docs/edit).

## One name, everywhere

A flow is `<verb>-<entity>`, singular kebab-case (`add-student`, `bulk-teacher`). That one
word names the flow file, its local folder, its files on the CDN and its manifest ids.
**hogwarts** is the internal name in every path; **balqalam** is only the public brand
drawn on screen.

| Asset | Local (`~/media/<repo>/`) | Manifest id | CDN (`cdn.databayt.org/hogwarts/`) |
| --- | --- | --- | --- |
| page still | `page/<slug>-<locale>.png` | `page/<slug>-<locale>` | `<locale>/<route>/page.avif` (home → `<locale>/page.avif`) |
| flow still | `<flow>/NN-<step>-<locale>.png` | `<flow>/<step>-<locale>` | `<locale>/<route>/<step>.avif` (+ `@2x`, `.webp`) |
| phone still | `<flow>/iphone-16/NN-<step>-<locale>.png` | `<flow>/iphone-16/<step>-<locale>` | `<locale>/<route>/iphone-16/<step>.avif` |
| tutorial | `<flow>/<flow>-<locale>.mp4` (+ `.av1.mp4`, `.poster.webp`, `.vtt`) | `<flow>/video-<locale>` | `<locale>/<route>/video.mp4` (+ `video.av1.mp4`, `video.poster.webp`, `video.vtt`) |
| reel | `<flow>/<flow>-<locale>.reel.mp4` | `<flow>/reel-<locale>` | `<locale>/<route>/reel.mp4` |
| support clip / story cut | `<flow>/<flow>-<clip>-<locale>.*` | `<flow>/<clip>-<locale>` | `<locale>/<route>/<clip>.mp4` |
| block media (ad, block reel) | — | your id | `<locale>/<route>/<file>.mp4` |
| raw take | `<flow>/raw/<flow>[-<part>]-<locale>.mov` | — | — |

- **The CDN mirrors the app URL, language first.** A flow's `export const route` is its home:
  `cdn.databayt.org/hogwarts/<locale>/<route>[/<flow>]/…`, the same shape as
  `<school>.databayt.org/<locale>/<route>`. add-student → `students/add` gives
  `hogwarts/ar/students/add/video.mp4` and `hogwarts/en/students/add/list.avif`; the two flows on
  `/school/bulk` get subfolders (`school/bulk/student`, `school/bulk/teacher`). publish refuses a
  flow module without a `route`.
- **Every key names its language, and no key carries a hash.** The narrowest width is bare and
  wider ones add `@2x` (`list.avif` 1600 px, `list@2x.avif` 2400 px); cache-busting is the
  manifest's `?v=<sha8>`.
- **Same name = overwrite.** No `-v2` / `-final`. The `NN-` order prefix stays in the local file
  and becomes the manifest entry's `order`, so the docs list stills in shot order.
- Keys are stable: a re-render overwrites the object and invalidates CloudFront for that key;
  browsers cache an hour, the edge a year, and manifest URLs carry `?v=<sha8>` so pages pick up
  new bytes at once.
- `~/media` sits outside every repo and mirrors to Drive (`record.sh sync`). Nothing is captured
  into a repo's `public/`.

## Publish

```bash
node ~/.claude/skills/shoot/scripts/shoot.mjs --flow add-student --lang ar,en --publish
node ~/.claude/skills/shoot/scripts/publish.mjs --flow add-student [--only stills|video] [--dry-run]
node ~/.claude/skills/shoot/scripts/publish.mjs --flow page
```

Each asset is uploaded, HEAD-verified and upserted into the product's
`media-manifest.json`; pages render it by id — `<FlowMedia flow="add-student" />`,
`<Shot id="add-student/created-ar" />`, `<TutorialVideo id="add-student/video-ar" />` — never
by URL. Publishing also stamps the repo sha into `~/media/manifest.json`, so
`record.sh stale` flags a still whose source (`export const block` / `paths`) has changed.

## Feeds social

A published flow is also what the social block offers as a feature's **real screens**. Name the
flow in that feature's `SPOTLIGHT.md` (`flows: [<flow>]`), then:

```bash
node scripts/spotlight-cdn.mjs          # hogwarts — refreshes the spotlight's "On the CDN" links
node scripts/social-concepts.mjs        # kun — rebuilds content/social/product-media.json; commit it
```

The screens then appear on Draft's concept card, the Publish rail and the Media box for that
feature. The format and the chain: [Spotlight](/docs/social/spotlight).
